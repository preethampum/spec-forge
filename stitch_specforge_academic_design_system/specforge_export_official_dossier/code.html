1. Course Overview & Prerequisites

This course offers a rigorous treatment of advanced algorithm design techniques and computational complexity theory. Topics include amortization, randomized algorithms, approximation algorithms for NP-hard problems, linear programming duality, streaming algorithms, and fixed-parameter tractability.

Prerequisites: CS201: Data Structures & Algorithms (Grade ≥ B), MA203: Discrete Mathematical Structures.
